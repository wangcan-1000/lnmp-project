## 🧠 我的排错心法（经过本项目验证）

1. **看日志**：服务启动失败，第一反应是看 `systemctl status` 和服务的专属日志文件。
2. **逐层排查**：Web 服务不可用，从网络层 -> 传输层 -> 应用层逐层验证，使用 `ping`、`netstat`、`curl -I` 等工具。
3. **安全为基线**：遇到 GPG 校验失败，不是去关掉校验，而是去找到并导入正确的密钥。
4. **善用外脑**：面对未知问题（如 EOL），先问清楚现象再动手，AI 和官方文档是最快的学习路径。
5. **复盘即实践**：记录故障案例，不是记录错误，而是记录一次完整的“诊断-解决”闭环。
